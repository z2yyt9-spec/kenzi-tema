# Kenzi Tema 🎨

Tema Dark Blue/Black untuk Pterodactyl Panel dengan tampilan modern dan sistem statistik real-time.

![Preview 1](assets/images/preview-1.png)
![Preview 2](assets/images/preview-2.png)

## ✨ Fitur
- 🌙 Warna dasar hitam kebiruan (dark blue/black theme)
- 📊 Menampilkan data CPU dan waktu runtime
- ⏰ Tampilan jam real-time (contoh: 21.05)
- 🟢🔴 Status server (Online/Offline)
- 👤 Menu Account Settings lengkap
- 🎨 Desain modern dengan efek glassmorphism
- 📱 Responsive untuk semua device
